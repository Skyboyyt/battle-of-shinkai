# Battle of Shinkai — WebGL test build

Test build of *Battle of Shinkai* (Unity 6 WebGL), published for phone and desktop browser testing.
Includes Phase 14: an optional, read-only Solana wallet connection. Players who own AxoRonin NFTs can play as them;
free characters are always available. The game never asks for a signature, a transaction, a seed phrase or a private key.

New: **private 1v1 Multiplayer** (PLAY → MULTIPLAYER → create a room and share its code, or join one). Guests can play;
the room server decides hits, damage, Perfect Parries and the result.

**Play:** https://skyboyyt.github.io/battle-of-shinkai/

This branch contains only the generated WebGL build (Gzip + decompression fallback for static hosting), not the game source.
